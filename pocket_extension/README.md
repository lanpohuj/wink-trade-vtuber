# ⌖ Winky Pair Sniper — Расширение для Pocket Option

Тактический встроенный виджет Winky Pair Sniper и отдельный счётчик сессии для Pocket Option (Manifest V3).

---

### Быстрый запуск в 1 клик (из пульта Winky):
В окне **Winky — пульт** просто нажмите большую оранжевую кнопку:
> **🎯 Открыть Pocket Option со встроенным WINKY PAIR SNIPER**
Chrome автоматически откроется с уже активированным расширением!

---

### Ручная установка в любой браузер за 10 секунд (Chrome, Brave, Arc, Edge):

1. Откройте страницу расширений в браузере: `chrome://extensions`
2. В правом верхнем углу включите тумблер **Developer mode** («Режим разработчика»).
3. В левом верхнем углу нажмите кнопку **Load unpacked** («Загрузить распакованное»).
4. Выберите папку `pocket_extension` из репозитория проекта:
   `/Users/alansalam/Wink Trade Pocket/pocket_extension`
5. Откройте Pocket Option (`https://po-ru4.click/` или `https://pocketoption.com`).
6. Готово! Прямо на странице появятся два тактических виджета:
   - **WINKY PAIR SNIPER** (справа): выбор цели, Market Pulse, 48-тиковый радар, спидометр сигнала.
   - **LIVE SESSION COUNTER** (слева): победы, поражения, винрейт с авто-подсчётом.

---

### Преимущества прямого встраивания в DOM:
- **Синхронный зум**: при приближении/отдалении страницы (`Cmd +` / `Cmd -`) или pinch-to-zoom на трекпаде Mac виджет масштабируется вместе с графиком как родная часть страницы!
- **Авто-считывание данных**: сам видит активную пару, payout доходности и тики котировок.
- **Озвучка Winky (LumeanTTS)**: голос `Марин китагава` (RU) и `Venti` (EN) озвучивает сигналы и синхронизирует эмоции 3D-аватара Winky.
