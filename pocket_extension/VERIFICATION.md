# Версия 2.3.0 — проверяемая торговая механика

## Что изменилось

Единственный путь решения о входе — `trading_core.js`. Ядро принимает только
котировки брокера с меткой пары и временем. Пиксели, случайный выбор направления,
форсированные входы после семи отказов и скрытые BUY/SELL-триггеры не участвуют
в решении. Графическое M1 и ширина видимой истории H2 не задают интервалы анализа:
S15/S30/M1/M2 строятся математически по временным меткам.

Нужно минимум 24 закрытых M1 и 12 M2 с непрерывной историей. При отсутствии
такой истории бот показывает прогрев и ждёт данные, не создаёт искусственные
свечи. M1 и M2 должны согласовать тренд. Для входа проверяются закрытый откат,
свеча подтверждения, EMA9/21, ATR, направленная эффективность, свежесть,
расстояние до ближайшего уровня и последние тики. Из кандидатов S15/S30/M1
выбирается наиболее полный сетап; длительность — соответственно 30/60/120 с.
Оценка условий /5 не является вероятностью выигрыша.

Перед кликом сетап проверяется снова. Отправленный ордер не переписывается
в WebSocket. Экспирация должна быть подтверждена полем Pocket. Состояние сделки
возникает только после ответа брокера с совпадающими парой, суммой, направлением,
временем и ID. Таймер использует абсолютное время закрытия из ответа брокера.

Результат берётся из числового net `profit` закрытого ордера с тем же ID.
Нулевой profit — возврат, без прибавления W/L. Неизвестная схема пакета,
неподтверждённое открытие или отсутствующий результат блокируют дальнейшие
входы. Баланс после списания ставки, цена в момент таймера и первая строка
истории больше не определяют исход. Блокировка сохраняется при перезагрузке
в `winky_unresolved_order`; удалять её можно только после ручной сверки всех
открытых ордеров. Старые счётчики v3/v4/v5 сохранены, новая статистика — v6.

Ставка фиксирована $50, без догонов. После трёх подтверждённых убытков подряд
авто-стрим выключается. Эта сумма не является рекомендацией по риску.

## Проверено автоматически

`node --test pocket_extension/trading_core.test.cjs`

Тесты проверяют закрытие свечей без использования будущего, точность малых цен,
чужие пары, устаревшие и неполные данные, флэт, направление EMA/ATR, положительные
синтетические сетапы с разной экспирацией, BUY/SELL-симметрию, масштаб цены,
WIN/LOSS/REFUND, сохранность отправляемого пакета, отбраковку чужого ордера,
подтверждение нужного ID и бинарное закрытие.

## Граница проверки

Синтетические тесты доказывают свойства кода, не доходность. Истории реальных
тиков и закрытых ордеров для walk-forward проверки в проекте нет. Скриншоты
сняты до закрытия ордеров и не подтверждают их окончательный исход.

Живой Chrome недоступен агенту (Computer Use отклонён). Схемы `successopenOrder`
и `successcloseOrder` проверены на моделируемых пакетах, а не на текущей сессии
Pocket. Неподдерживаемый ответ остановит входы; расширять адаптер следует по
реальному обезличенному пакету, без догадок. Сначала необходимо обновить
распакованное расширение 2.3.0 и перезагрузить страницу Pocket с выключенным
авто-стримом, затем проверить жизненный цикл в демо-режиме. Деплой VPS сам
по себе не перезагружает локальное Chrome-расширение.
