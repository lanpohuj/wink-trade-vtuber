# Winky: живое сопровождение, 2.3.3

Контекст передаётся прежним POST /api/winky/trade_phase, без новых маршрутов.
Добавлены auto_stream, search_generation, data_status, setup/setup_confirmed,
open_observed, замороженные entry_factors/entry_periods/entry_source,
entry_observed_at, closes_at, next_stake, last_result и измеренная волатильность.
Heartbeat раз в секунду не освежает возраст исходного наблюдения. GET того же
маршрута возвращает диагностику commentary и последние 100 событий.

Речь воспроизводит прежний SpeechController. Приоритет: результат 0, открытие 1,
важное продолжение после результата 2, ответ зрителю 3, фон 4. Подтверждённое
открытие выбирает запись с причиной при наличии подходящей пары direction/setup;
иначе остаётся прежняя пригодная запись. Нет дополнительного клика/ордера.

StreamDirector работает с интервалом 250 мс. Новая фоновая запись допускается
через 4–7 с после фактического окончания речи. Готовый чат важнее фона;
подготовка ответа чату его не блокирует. В очереди не более одного фонового
элемента. Устаревшие сообщения освобождают резерв колоды. Причина экспирации
звучит один раз за сделку. Обращение к зрителям — не чаще 45 с.

Важное пояснение перекрытия ставится после фактически начавшейся реплики
результата, без ожидания фонового интервала. Оно не прерывает речь и перестаёт
быть допустимым при открытии следующей сделки/изменении следующей ставки.

Фон не начинает звучать при выключенном автостриме, паузе голоса либо возрасте
heartbeat более трёх секунд. До закрытия сделки должны помещаться весь файл
и запас две секунды. Результат/открытие/чат обслуживаются прежней очередью.

Волатильность для речи: медиана диапазона последних трёх полных свечей / медиана
предыдущих двадцати >=1.8; все свечи одного источника и периода. Признак не влияет
на стратегию. HIGH_RISK_MARKET сам по себе не даёт реплику про шторм.

Для «срезало» нужны LOSS, сопоставленный BROKER_DEAL_RESULT с числовыми
open_price/close_price и close_time, положительная котировка в последние три
секунды и отрицательный итог не дальше 0.1 ATR. Цены из пикселей не используются.
Отсутствие этих необязательных полей оставляет обычную реакцию на минус;
формула определения результата и балансовый fallback не менялись.

Новый банк: assets/voices/commentary_v1, 160 файлов / 80 на язык. Подключается
дополнительно к активному банку; отклонённый fish_v3 не активируется. Голоса
Марин RU / Venti EN, профиль .82/.85, speed1.06, balanced. Сценарии и измерения:
commentary-160.json, commentary-qc.json. Скрипты tools/commentary_catalog.py и
build_commentary_bank.py поддерживают возобновление без повторной оплаты кеша,
предварительную проверку всех текстов, QC и отдельную выборочную приёмку.

Все 160 файлов декодированы, измерены и расшифрованы локально. Два сомнительных
дубля заменены; новая автоматическая проверка не содержит замечаний. Их слуховая
приёмка запрошена отдельно. До принятия двух замен банк не включается. Агент
не заявляет личное прослушивание: аудиовход модели недоступен.

Офлайн: 53 Python/HTTP-проверки, 116 Node-проверок (113 прежних и 3 новых).
Модели времени/DOM/WS не заменяют локальное воспроизведение и демо-цикл Pocket.
Видео владельца длится 49 с, его аудиодорожка содержит цифровую тишину (-91dB).
