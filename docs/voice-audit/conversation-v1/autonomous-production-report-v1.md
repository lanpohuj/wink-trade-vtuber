# Винки: озвученный пилот RU и репетиция

**Обновление 17 ноября:** последующая выборочная приёмка, включение 75 записей и проверка очереди описаны в [отчёте выпуска](autonomous-pilot-release-report.md). Ниже сохранён статус на момент подготовки репетиции.

16 ноября 2026. После принятия исправленного первого направления владелец поручил продолжать ранее представленный план с пределом новых расходов $0.10. Конкретный заказ и основание продолжения сохранены в `owner-autonomous-production-spend-approval-v1.json`.

## Результат

Озвучены **76 карточек / 68 разных текстов** голосом Марин. Два ранее принятых MP3 сохранены; три записи уже находились в платном кеше. Для исходной партии выполнены 63 новых платных запроса. Восемь адресных замен после QC исправляли только конкретные проблемы; одинаковые слоты направления использовали одну запись, без повторной оплаты копий. Учтённый расход всей партии с заменами — **$0.067140**, ниже согласованных $0.10. Рабочие настройки и голоса RU/EN не менялись.

75 карточек / 67 уникальных аудио прошли автоматический QC. Одна карточка — `autonomous_ru_loss_04`, «А-а, досадно!» — оставлена для проверки на слух из-за расхождения распознавания. Её текст не удалён, файл не выдаётся за принятый и не допускается к обычному выбору. Повторные платные попытки остановлены. Автоматическая проверка не принимает естественность остальных записей вместо владельца.

Для каждого текущего файла подготовлена отдельная разметка акцентов **из прежнего набора движений**, привязанная к SHA256. Это черновик для сценической приёмки; в рабочий выбор разметка не включается до принятия. Короткое аудио получает малое движение вместо сжатия большого жеста. Физические движения, `avatar.js` и указатель рабочего банка сохранены.

## Материалы для оценки

- Короткая репетиция **2:21**: `artifacts/winky-autonomous/bank-v1/winky-bank-highlights.mp4`.
- Полная постановочная версия **3:54**: `artifacts/winky-autonomous/bank-v1/winky-autonomous-rehearsal.mp4`.
- Страница оценки репетиции и всех файлов: `autonomous-production-review.html`; экспорт — `winky-autonomous-production-review.json`.
- Тексты, условия и оригинальный заказ: `autonomous-production-order-v1.md`.

В сценах показаны поиск, вход, ожидание, подтверждённый исход, знакомство, подарок и результат во время ответа с возвращением к собеседнику. На репетиции используются настоящие MP3, реальная модель и прежние движения. Сообщения и сделки постановочные, ответы чата взяты из уже принятых записей. Это не проверка живого LLM, TikTok, Pocket или удержания зрителей. Фоновая музыка отсутствует, чтобы оценивать голос.

На странице можно принять сцену и подачу банка по выборке, не приписывая личное прослушивание каждому файлу. Спорный QC не обходится общей выборочной приёмкой: для него требуется отдельное прослушанное решение. Оценка связана с точным набором SHA256 и версией сцен; изменённая запись не наследует старое решение. Импорт оценок сохраняет банк неактивным.

## Техническая проверка

- **240 Python-тестов**, включая оплату в пределах согласованного лимита, сохранение старых дублей, совместное использование копий, идемпотентный повтор запуска и приёмку без выдуманного прослушивания.
- **35 JS-тестов** прежней анимационной системы; **10 проверок** реальной модели в браузерном стенде, без ошибок JavaScript.
- В готовом MP4 есть видео и аудио; длительность короткой версии 141 секунда. Уровни с учётом тишины: средний −26.7 dB, максимум −7.4 dB. Это не слуховая оценка шума или интонации.
- Шесть кадров проверены по пикселям: модель видима. Изображения и контрольный лист сохранены рядом с видео.
- Два новых файла проверены в изолированном нативном WKWebView с настоящим AVAudioPlayer и нулевой громкостью. Разница позиции аудио и состояния кадра: медиана **50.23 мс**, p95 **55.67 мс**, максимум **66.17 мс**. Это транспорт/кадр, не акустическая задержка колонок. Агенту не приписывается прослушивание. Новых TTS-запросов в этой проверке не было.

## Дальнейший порядок

Рабочий процесс Винки и активный банк не переключались. После оценки целой сцены — выпуск принятого состава, двухчасовая локальная репетиция с реальной очередью и файлами, проверка на QT Demo и ограниченный живой пилот. До этого нельзя считать весь двухчасовой эфир проверенным.

Параллельно подготовлена английская адаптация: `autonomous-bank-en-draft.md`, 76 карточек / 68 текстов, Venti для будущего голоса. Она сохраняет те же условия, исключает четыре отвергнутых вопроса, остаётся неутверждённым черновиком и не озвучивалась. После пилота банк расширяется по выявленным пробелам до целевых объёмов; количество записей само по себе не доказывает разнообразие эфира.

Торговый код, стратегия, статистика, публичные API бота/Mini App и серверные части в этот выпуск не входят.
